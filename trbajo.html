​
Identificación de la Problemática y Solución

Problemática: Información académica dispersa, diseño visual obsoleto, proceso de registro manual ineficiente sin validaciones ni interactividad moderna.

Propuesta de Solución: Micrositio web responsivo basado en HTML5 semántico, CSS3, Bootstrap 5 y validación interactiva en JavaScript con arquitectura de 2 columnas.

​

Respuestas a Preguntas Guía

  • 1. ¿Cómo debería estructurarse la página web para que la institución comunique sus servicios? Mediante bloques semánticos con HTML5: Encabezado fijo con barra de navegación, sección Héroe con llamados a la acción claros, grilla de beneficios institucionales, tarjetas de programas académicos, formulario de registro interactivo y pie de página institucional completo.
  • 2. ¿Qué elementos de diseño visual, maquetación y estilo permitirán mejorar la usabilidad? Uso combinado de CSS Grid y Flexbox para layouts adaptables, el framework Bootstrap 5 para componentes limpios y consistentes, paleta corporativa de tonos azules y blancos con acentos verdes brillantes para los botones de conversión (CTA).
  • 3. ¿De qué manera JavaScript aporta interactividad útil sin afectar la interfaz? Validación en tiempo real de entradas del formulario, prevención del envío por defecto, manipulación dinámica del DOM para mostrar alertas de éxito/error de forma inmediata y navegación fluida tipo Smooth Scroll.
  • 4. ¿Qué datos debe solicitar el formulario web y cómo se valida? Solicita Nombre completo, Correo electrónico, Teléfono celular (9 dígitos), Programa de interés y aceptación de términos. Se valida mediante Expresiones Regulares (RegEx) previniendo envíos con datos corruptos o incompletos.
  • 5. ¿Cómo demuestra la propuesta final la integración correcta de tecnologías y UX/UI? Presenta un código limpio, modular, accesible, totalmente adaptable a dispositivos móviles bajo la filosofía Mobile First y alineado estrictamente a los estándares corporativos actuales.
